# 小球越狱

一条 33 秒的竖屏剧情短视频（1080×1920，60fps），适合抖音、快手、视频号、小红书、TikTok 和 Reels。结尾画面和开头完全一致，可以无缝循环播放。

- 成片：[`output/story.mp4`](output/story.mp4)
- 封面：[`output/cover.jpg`](output/cover.jpg)
- 源码：[`make_video.py`](make_video.py)（运行 `pip install pycairo numpy scipy && python3 make_video.py` 可重新生成，需要 ffmpeg 和文泉驿正黑字体）

## 为什么它有机会火

- **有角色**：小球有表情，有情绪起伏（难过 → 发现 → 拼搏 → 胜利 → 反转），观众会代入。
- **前 3 秒有悬念**：“撞一下墙就变大”是一个奇怪的设定，配慢动作和“？！”，让人想看它会怎样。
- **反转结局**：好不容易冲出去，却发现外面还有更大的圈。这能引发对“内卷”和“人生困境”的共鸣，适合转发。
- **无缝循环**：结尾和开头的画面一模一样，观众容易不知不觉看第二遍，完播率和复播率更高。
- **用问题结尾**：“你被困在第几个圈里？”引导观众评论。
- **声画同步**：每次碰撞弹出《欢乐颂》的下一个音符，配合心跳、裂纹声、爆炸声和唱片急停的音效。
- **没有版权风险**：画面和声音都由程序生成，旋律是公有领域的贝多芬《欢乐颂》。
