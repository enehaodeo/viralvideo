# 球每弹一次就变大一点

一条 32 秒的竖屏解压短视频（1080×1920，60fps），适合抖音、快手、视频号、小红书、TikTok 和 Reels。

- 成片：[`output/bounce.mp4`](output/bounce.mp4)
- 封面：[`output/cover.jpg`](output/cover.jpg)
- 源码：[`make_video.py`](make_video.py)（运行 `pip install pycairo numpy && python3 make_video.py` 可重新生成，需要 ffmpeg 和文泉驿正黑字体）

## 为什么它有机会火

| 要素 | 做法 |
| --- | --- |
| 前 1 秒的钩子 | 第一帧球就在下落，标题直接抛出问题：“猜猜它要弹几次才能填满？” |
| 让人看到最后 | 底部实时显示弹跳次数和填充百分比，答案只在结尾揭晓 |
| 越来越紧张 | 球越大，弹得越快，音符越密，最后炸开 |
| 解压的画面 | 球留下彩虹管道一样的轨迹，每次碰撞都有火花和圆环闪光 |
| 声画同步 | 每次碰撞弹出《欢乐颂》的下一个音符，音频由模拟结果直接生成 |
| 引导评论 | 结尾写“你猜对了吗？评论区报出你的答案”，刺激评论和重看 |
| 没有版权风险 | 画面和声音都由程序生成，旋律是公有领域的贝多芬《欢乐颂》 |

## 发布文案（直接复制）

**标题：** 球每弹一次就变大一点，猜猜它要弹几次才能填满？看到最后🤯

**话题：** #解压 #治愈系 #物理模拟 #强迫症福音 #猜数字 #欢乐颂

**置顶评论：** 先别看结尾，把你猜的数字打在评论区👇

## 发布建议

- 封面用 `output/cover.jpg`，计数器被换成了“???”，不会剧透答案。
- 发布时段可以选晚上 7–10 点，或者午休 12–13 点。
- 想做成系列，可以改 `make_video.py` 顶部的参数，比如 `GROW`（每次变大多少）、`R0`（初始大小）、`MELODY`（换一首曲子），每一期都能出一个新答案。
